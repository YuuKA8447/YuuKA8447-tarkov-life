# 更新说明 V1.4.1.0

## 版本号说明

- 按 `MAJOR.MINOR.PATCH.BUILD` 四段规则，本次修正底部锚点下的浮窗排列，属于向下兼容的问题修复，递增第 3 位 PATCH 并将 BUILD 归零：`1.4.0.0` → `1.4.1.0`。
- 程序内部版本、EXE 文件名、PE FileVersion / ProductVersion、界面关于行、ZIP 名与校验文件均统一为 `1.4.1.0`。

## 本版改动

- **底部锚点改为得分浮窗在上、编号浮窗贴底**。浮窗位置选居中下、左下或右下时，`SC <分值>` 小窗显示在编号浮窗上方，编号浮窗保持贴住屏幕底部 18 px 边距；顶部锚点仍为编号在上、得分在下，两个浮窗始终保留 6 px 间距。
- 左右与居中对齐规则不变：右侧锚点对齐右边缘、左侧锚点对齐左边缘、居中锚点各自居中。
- 其余行为与 V1.4.0.0 相同：测试模式状态卡片显示详细得分读数，得分浮窗只显示 `SC <分值>` 且尺寸小一档，停止监控后自动收起。
- 识别模板、阈值、撤离状态机、音效与按键行为均未改动；`monitor.marshal` 与 `detector.marshal` 未改动。

## 验证

- `build\_test_two_overlays.py` 布局与文本检查 42 项全部通过，覆盖顶部与底部三个锚点的上下顺序、独立宽度、边缘对齐、6 px 间距、停止收起与 TclError 容错。
- 2560×1600 假游戏端到端：浮窗位置设为右下并开启测试模式，A 页武装后上方显示 `SC 0.904`、下方显示 `TKF-7314-A`；F1 停止后得分浮窗消失，仅保留贴底的 `TKF-7314-0`。
- 50 张源图 + 7 条过曝条带回归、撤离流程状态机测试、`--smoke-test`（退出码 0）、`validate_final`（21 张模板解码）全部通过。
- ZIP `testzip` 无错误、8 个条目齐全；EXE 哈希与 `SHA256.txt` 一致。
