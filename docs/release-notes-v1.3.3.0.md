## 本次修复

### 过曝画面识别得分偏低

用户挑出的 21 张低分素材里，18 张 A 页 `combat_score` 只有 0.502–0.594，正常画面为 0.85–0.95；过曝页签的模板分数同样到不了 0.70。样本全部带明显过曝。

根因是过曝损失了高光处的局部梯度，而不是全局亮度。A 页 `body_shape` 用 `Canny(35,90)` 提取人体轮廓再做 `distanceTransform`，泛白区域提不到边缘，分数随之下滑；页签的灰度相关性同理。`TM_CCOEFF_NORMED` 对全局线性亮度/对比度变化免疫，所以“加亮模板”没有收益，必须做局部对比度增强。

## 修复内容

- `scores_top` 改为两遍评分：第一遍按原逻辑计算 `body_shape` 与 `hotbar`；仅当 `body_shape >= 0.35` 时，用 `CLAHE(clipLimit 2.0, tileGridSize 8×8)` 对同样的 `hud_body` / `hud_body_169` / `hud_hotbar` 裁剪区域重算一遍，取较高分。
- 门控依据：50 张回归中战斗 HUD 的 `body_shape` 最低 0.493，菜单页最高 0.285，0.35 位于两者之间，菜单页不会因为增强被判成 A。
- `tabs_D`～`tabs_J` 每个页签改为取「原图 / CLAHE 2.0 / CLAHE 4.0」三次匹配的最高分，再参与 `0.70` 直接命中判定。
- 更激进的参数（clip 8–16、4×4 网格）会把 J 页翻成 G / F，已放弃；`tab_boxes` 亮度兜底与门槛保持不变。

## 验证结果

- 18 张低分 A 页：最低 `0.502 → 0.550`，平均 `0.557 → 0.590`，单张 +0.024～+0.051，判定仍全部为 A。
- H 页 `0.593 → 0.713`、I 页 `0.547 → 0.727`，越过 0.70 直接命中；J 页仍 0.594，继续走亮度兜底。
- 50 张实机截图全帧与裁剪条带、7 条过曝页签条带、M 页、黑屏与“找到撤离点”黑名单全部通过。
- 单帧平均 40.3 ms、最大 81.5 ms；撤离流程状态机测试通过；`--smoke-test` 退出码 0。
