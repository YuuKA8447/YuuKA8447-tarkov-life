## 本次修复

### 半透明 / 过曝菜单页识别失败或误判 U

部分菜单页在角色装备栏打开、画面半透明或整体过曝时，页签条泛白，D–J 页签模板分数跌到 0.30–0.61，低于 `0.70` 阈值；同时右上角“返回”区域可能匹配 `menu_return` 0.844，旧逻辑会先判为 `U`。实测两张 16:10 背包页分别得到 `0` 与 `U`。

根因是 `TM_CCOEFF_NORMED` 对亮度和对比度敏感。页签条整体提亮后，正常页签模板的灰度分布不再匹配；但激活页签仍明显比相邻页签更亮，这一结构特征没有丢失。

### 修复方式

- 页签模板全部低于 `0.70` 后启用亮度兜底：计算 D–J 七个页签框的平均亮度，取最高者；要求领先第二名至少 `25` 灰度、最高值至少 `95`。
- 使用右上角“返回”区域的 95 分位亮度 `≥130` 与 Canny 边缘密度 `≥0.07` 做门控，避免战斗 HUD、地图、设置页与“找到撤离点”横幅误判。
- 兜底位于 `U` 判定之前，半透明页不会再被“返回”模板抢判为 `U`。
- 复核切片时发现 `联想截图_20261028191050.png` 的激活页签为“总览”，已从 D 目录移到 `画面识别 E 二级菜单,总览\识别画面E.png`，分类记录同步更正。
- 两张 16:10 半透明背包页加入回归（`B3`/`B4`）；7 条过曝页签切片合成 2560×1600 画面后加入回归（D/E/F/G/H/I/J）。

### 回归结果

- 50 张源图全帧与裁剪条带均通过；7 条过曝页签条带全部通过。
- 两张半透明背包页由 `0` / `U` 修正为 `D`；7 条条带分别得到 D/E/F/G/H/I/J。
- 48 张既有回归素材无新增误判，C/K/L/M/A/B 页面保持原结果。
- 单帧平均 36.2 ms，最大 77.1 ms。
- `validate_final` 21 张模板解码、四模块回读全部通过；`--smoke-test` 退出码 0。

## 快速上手

1. 解压 ZIP，保持 `icons` 文件夹与 EXE 同级，双击 `从零开始的塔科夫生活_V1.3.2.4.exe`。
2. 启动时如弹出管理员权限提示，选择“是”。发送 Alt+F4 与自动按键需要管理员权限；选择“否”时程序会继续以普通权限运行。
3. 进入游戏后按 **F1** 开启或关闭监控；检测模式默认不开启。
4. 屏幕右上角会常驻显示当前界面编号，例如 `TKF-7314-0`、`TKF-7314-A`、`TKF-7314-Z`。
5. 识别到撤离点绿色横幅 `TKF-7314-B` 后，程序播放关闭提示音并暂停 Alt+F4，但继续检测。
6. 撤离过场依次经过黑屏 `TKF-7314-Z` 与撤离结束 `TKF-7314-M`；识别到 `M` 后不再发送 Alt+F4，3 秒后停止监控并显示 `TKF-7314-0`。
7. “退出兜底”默认关闭。启用后它是 Alt+F4 之后的兜底：等待设为 0 秒时会立即强制结束游戏进程。此操作可能丢失战局进度，请确认后再使用。
8. 浮窗位置在“进阶设置 → 浮窗位置”中调整，选择“关闭”会隐藏浮窗。

## 识别编号

`A` 战斗 HUD · `B` 撤离点 · `C` 游戏主页/暂停 · `D` 背包 · `E` 总览 · `F` 健康 · `G` 技能 · `H` 地图 · `I` 任务 · `J` 成就 · `K` 控制台 · `L` 三级菜单/设置。

兜底：`U` 未知菜单 / 返回页签 · `Z` 黑屏加载 / 撤离过渡 · `M` 撤离结束 / 战局结束 · `0` 未识别。

## 安全提示

- 仅截取屏幕顶部条带做模板匹配，不读取内存、不注入进程、不修改游戏文件。
- 强制结束只匹配 `EscapeFromTarkov.exe`，不会结束其他进程。
- Alt+F4、自动按键与强制结束可能违反游戏服务条款或导致战局进度丢失，请在了解风险后自行决定是否使用。
- 本项目与 BattlEye、Battlestate Games 无关联。

## 已知限制

- 亮度兜底依赖 D–J 页签的固定位置；若游戏 UI 缩放或页签位置大幅变化，仍需重新生成模板。
- 过曝严重到激活页签与相邻页签亮度差小于 25 灰度时，兜底可能不触发；此时会回落到原有 `U` / `0` 逻辑。
- C 页 5 张模板共 30 个变体，单帧耗时高于其他页面；本轮平均 36.2 ms、最大 77.1 ms。
- 常驻徽标固定在主屏幕，不跟随游戏窗口；独占全屏可能遮挡置顶窗口。
- 三套主题 ICO 不内嵌，需随发布包放在 `icons/`；缺少时窗口与托盘图标回退默认图标，识别与音效不受影响。
