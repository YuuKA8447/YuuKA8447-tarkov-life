# 从零开始的塔科夫生活 V1.3.2.3 正式版

发布日期：2026-10-28

基于顶部条带模板匹配的 Escape from Tarkov 界面识别与监控辅助。只截屏，不读取游戏内存、不注入进程、不修改游戏文件。

## 版本号说明

- 本版本是 `V1.3.2.2` 的问题修复版，按 `MAJOR.MINOR.PATCH.BUILD` 四段规则递增 PATCH：`1.3.2.2 → 1.3.2.3`。
- 程序内部版本、EXE 文件名、PE FileVersion / ProductVersion、界面关于行、ZIP 名与校验文件均统一为 `1.3.2.3`。
- 本版为本地构建，尚未上传 GitHub；GitHub 最新发布仍为 `v1.3.2.2`。

## 本次修复

### C 页跨地图识别失败

C 页（游戏主页 / 暂停覆盖层）原先只有一张 `pause_C` 模板，取自机房截图，匹配的是 `ESCAPE FROM TARKOV` 大字标志。该标志属于地图背景投影，不是固定 UI，各地图在归一化条带中的文字位置差异明显：

- 机房 92 px、16:9 实机 101 px、实验室 129 px、森林 129 px、工厂 130 px、无名者 159 px。
- 原模板对实验室、工厂、无名者、森林的得分仅 0.35–0.42，低于旧阈值 `0.62`，4 张地图全部识别失败。

### 修复方式

- 新增 4 张识别特征模板：`识别特征3.png`（实验室）、`识别特征4.png`（工厂）、`识别特征5.png`（无名者）、`识别特征6.png`（森林），按 `ui识别\识别特征与识别画面.txt` 的命名规则放在 `ui识别\画面识别 C 二级菜单,游戏主页面\`。
- 机房、实验室、工厂、无名者、森林 5 张模板组成 C 页家族；每张生成纵横比 `1.0 / 1.2` × 缩放 `0.9 / 1.0 / 1.1` 共 6 个半分辨率变体，匹配时取最高分。
- C 页阈值由 `0.62` 提高到 `0.70`；命中 `0.85` 后提前结束。
- 内嵌模板 17 → 21 张，回归素材 41 → 48 张。

### 回归结果

- C 页得分：机房 1.000、实验室 0.993、工厂 1.000、无名者 0.985、森林 0.989；16:9 实机 0.932；非 C 页最高 0.469。
- 48 张源图全帧与裁剪条带均 48/48；非 M 素材最高误匹配 0.487，低于 `0.78`。
- 合成 2560×1440 黑帧判定 `Z`；“找到撤离点”黑名单 380/430/500 px 三档全部拒绝。
- 单帧平均 34.8 ms，最大 71.4 ms。
- `validate_final` 21 张模板解码、四模块回读全部通过；`--smoke-test` 退出码 0。

## 快速上手

1. 解压 ZIP，保持 `icons` 文件夹与 EXE 同级，双击 `从零开始的塔科夫生活_V1.3.2.3.exe`。
2. 启动时如弹出管理员权限提示，选择“是”。发送 Alt+F4 与自动按键需要管理员权限；选择“否”时程序会继续以普通权限运行。
3. 进入游戏后按 **F1** 开启或关闭监控；检测模式默认不开启。
4. 屏幕右上角会常驻显示当前界面编号，例如 `TKF-7314-0`、`TKF-7314-A`、`TKF-7314-Z`。
5. 识别到撤离点绿色横幅 `TKF-7314-B` 后，程序播放关闭提示音并暂停 Alt+F4，但继续检测。
6. 撤离过场依次经过黑屏 `TKF-7314-Z` 与撤离结束 `TKF-7314-M`；识别到 `M` 后不再发送 Alt+F4，3 秒后停止监控并显示 `TKF-7314-0`。
7. “退出兜底”默认关闭。启用后它是 Alt+F4 之后的兜底：等待设为 0 秒时会立即强制结束游戏进程。此操作可能丢失战局进度，请确认后再使用。
8. 浮窗位置在“进阶设置 → 浮窗位置”中调整，选择“关闭”会隐藏浮窗。

## 识别编号

`A` 战斗 HUD · `B` 撤离点 · `C` 游戏主页/暂停 · `D` 背包 · `E` 总览 · `F` 健康 · `G` 技能 · `H` 地图 · `I` 任务 · `J` 成就 · `K` 控制台 · `L` 三级菜单/设置。

兜底：`U` 未知菜单 / 返回页签 · `Z` 黑屏加载 / 撤离过渡 · `M` 撤离结束 / 战局结束 · `0` 未识别。

## 安全提示

- 仅截取屏幕顶部条带做模板匹配，不读取内存、不注入进程、不修改游戏文件。
- 强制结束只匹配 `EscapeFromTarkov.exe`，不会结束其他进程。
- Alt+F4、自动按键与强制结束可能违反游戏服务条款或导致战局进度丢失，请在了解风险后自行决定是否使用。
- 本项目与 BattlEye、Battlestate Games 无关联。

## 已知限制

- C 页匹配依赖地图背景中的标志位置；新增地图或大幅修改 HUD 缩放、分辨率后，需要补模板或重新生成。
- C 页 5 张模板共 30 个变体，单帧耗时高于其他页面；本轮平均 34.8 ms、最大 71.4 ms。
- 常驻徽标固定在主屏幕，不跟随游戏窗口；独占全屏可能遮挡置顶窗口。
- 三套主题 ICO 不内嵌，需随发布包放在 `icons/`；缺少时窗口与托盘图标回退默认图标，识别与音效不受影响。
