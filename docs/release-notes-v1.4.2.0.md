# V1.4.2.0 识别热路径提速（2026-10-31）

单帧识别耗时降低约 67%，识别结果与 V1.4.1.1 完全一致。

## 版本号

按 `MAJOR.MINOR.PATCH.BUILD` 四段规则，本次属用户可感知的帧耗时改善，递增第 3 位 PATCH 并把 BUILD 归零：`1.4.1.1 → 1.4.2.0`。

## 性能

| 指标 | V1.4.1.1 | V1.4.2.0 | 变化 |
| --- | --- | --- | --- |
| 平均 | 36.65 ms | 11.94 ms | −67.4% |
| p50 | 33.01 ms | 8.51 ms | −74.2% |
| p95 | 56.32 ms | 32.68 ms | −42.0% |
| 最大 | 77.08 ms | 50.87 ms | −34.0% |
| 超 33 ms 预算的样本 | 26 张 | 3 张 | −23 |

## 主要改动

- 撤离结束模板不再每帧跑 42 个缩放变体，改为 3 个变体探测、必要时才补齐剩余 39 个。
- 单帧灰度图只转换一次，供人形、快捷栏、撤离与结束匹配共用。
- CLAHE 实例缓存复用，不再每次匹配重建。
- 界面状态卡片改为差异刷新，值未变化时不触碰 Tk 控件。

## 未改动

识别模板、全部判定阈值、撤离状态机、Alt+F4 与自动按键行为保持不变。B 页黑名单与 C 页模板族未优化，因此仍有 3 张样本超过 33 ms。

## 验证

97 条样本（90 张测试图 + 7 条过曝切片）判定与得分逐位一致；50 图回归、撤离状态机、布局 42 项、`--smoke-test`、`validate_final` 全部通过。
