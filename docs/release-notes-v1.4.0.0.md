基于顶部条带模板匹配的 Escape from Tarkov 界面识别与监控辅助。只截屏，不读取游戏内存、不注入进程、不修改游戏文件。

## 本次新增

### 状态卡片得分读数

开启测试模式并开始监控后，状态卡片的分数行显示当前界面判定所依据的得分与分项：

- A 页：战斗得分、人形轮廓、快捷栏。
- B 页：撤离标题得分、绿色占比。
- C 页：主页面得分。
- D–J 页：页签得分与次高分；走亮度兜底时显示页签亮度（/255）与亮度差。
- K / L / M / U：控制台、设置、撤离结束、返回得分。
- Z：黑屏；0：无匹配，并附战斗得分与最高页签得分，便于排查误判。

测试模式下分数行使用高亮色；普通模式恢复监控线程原有的分数摘要。界面不再直接绑定 monitor 的 `scores` 变量，改由 150 ms 刷新循环统一渲染。

### 独立得分浮窗

测试模式监控中，编号浮窗下方出现第二个同款浮窗，只显示 `SC <分值>`：

- 比编号浮窗小一档：9 pt 字号、8×2 内边距（编号浮窗为 11 pt、10×4）。
- 与编号浮窗同底色、同边框色，间距固定 6 px。
- 颜色随界面变化：A 页琥珀、B 页红色、安全页绿色、其他页面灰色。
- 右侧锚点对齐右边缘，左侧锚点对齐左边缘，居中锚点各自居中；顶部锚点向下排列，底部锚点整组上移。
- 停止监控、关闭测试模式或关闭浮窗后自动收起。
- 两个浮窗每 0.5 秒同步重设置顶与鼠标穿透样式，游戏切回前台后不会只恢复编号浮窗。
