## 快速上手

1. 解压 ZIP，双击 `从零开始的塔科夫生活_V1.2.0.1.exe`。
2. 启动时如弹出管理员权限提示，选择“是”。发送 Alt+F4 与自动按键需要管理员权限；选择“否”时程序会继续以普通权限运行。
3. 进入游戏后按 **F1** 开启或关闭监控；检测模式默认不开启。
4. 屏幕右上角会常驻显示当前界面编号，例如 `TKF-7314-0`、`TKF-7314-A`、`TKF-7314-L`。
5. 只有“停留在撤离点内”绿色横幅会识别为撤离点并停止监控；识别到后不会发送 Alt+F4。
6. “退出兜底”默认关闭。启用后它是 Alt+F4 之后的兜底：等待设为 0 秒时会立即强制结束游戏进程。此操作可能丢失战局进度，请确认后再使用。
7. 自动按键默认关闭、间隔 30 秒、按键 F2；HUD A 就绪后立即发送一次，之后每 30 秒一次。
8. 浮窗位置在“进阶设置 → 浮窗位置”中调整：居中上、居中下、左上、右上、左下、右下。

## 识别编号

`A` 战斗 HUD · `B` 撤离点 · `C` 游戏主页/暂停 · `D` 背包 · `E` 总览 · `F` 健康 · `G` 技能 · `H` 地图 · `I` 任务 · `J` 成就 · `K` 控制台 · `L` 三级菜单/设置。

兜底：`U` 未知菜单 · `M` 黑屏 · `0` 未识别。

## 安全提示

- 仅截取屏幕顶部条带做模板匹配，不读取内存、不注入进程、不修改游戏文件。
- 强制结束只匹配 `EscapeFromTarkov.exe`，不会结束其他进程。
- Alt+F4、自动按键与强制结束可能违反游戏服务条款或导致战局进度丢失，请在了解风险后自行决定是否使用。
- 本项目与 BattlEye、Battlestate Games 无关联。

## 已知限制

- 源图没有可用的倒计时数字模板，撤离保护依赖绿色横幅本身。
- 识别依赖 UI 位置与缩放；大幅修改 HUD 缩放、分辨率或界面布局后，需要重新生成模板。
- 常驻徽标固定在主屏幕，不跟随游戏窗口；独占全屏可能遮挡置顶窗口。
- 源图未覆盖确认、战局结束页面，相关界面码已移除。
