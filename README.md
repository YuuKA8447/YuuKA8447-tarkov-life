## 快速上手

1. 解压 ZIP，保持 `icons` 文件夹与 EXE 同级，双击 `从零开始的塔科夫生活_V1.4.1.0.exe`。
2. 启动时如询问管理员权限，按需选择；发送 Alt+F4 与自动按键需要管理员权限。
3. 进入游戏后按 **F1** 开启或关闭监控。
4. 屏幕右上角会显示当前界面编号，例如 `TKF-7314-0`、`TKF-7314-A`、`TKF-7314-Z`。开启测试模式后会出现同款独立得分浮窗（只显示 `SC <分值>`，更小一档）：顶部锚点时在编号下方，底部锚点时在编号上方，停止监控后自动收起。
5. 撤离过场依次经过 `B` 绿色横幅、`Z` 黑屏与 `M` 撤离结束；识别到 `M` 后 3 秒停止监控。
6. “退出兜底”默认关闭；启用后等待 0 秒会立即强制结束游戏进程，可能丢失战局进度。
7. 浮窗位置在“进阶设置 → 浮窗位置”中调整：关闭、居中上、居中下、左上、左下、右上、右下。

## 识别原理

![21 张内嵌模板](docs/images/templates-grid.png)

1. 只截取游戏画面顶部条带：`strip_h = round(full_h * 240 / 1080)`。
2. 统一缩放到 `1920 × 240`，转换为灰度 / Canny 边缘图。
3. 使用 21 张模板做灰度或边缘匹配，判定顺序：撤离结束 `M` → 黑屏 `Z` → 撤离 `B` → 强 HUD `A` → 菜单 `K/L/页签/U/C` → 弱 HUD 回落 `A` → `0`。
4. 战斗 HUD 分数：`0.70 × 人体轮廓边缘支持 + 0.30 × 快捷栏灰度匹配`；16:9 与 16:10 使用独立人体轮廓模板。
5. C 页把机房、实验室、工厂、无名者、森林 5 张标志模板逐一匹配并取最高分，每张 6 个变体，阈值 `0.70`；5 张 16:10 地图得分 0.985–1.000，16:9 实机 0.932，非 C 页最高 0.469。
6. `end_M` 使用 X/Y 独立多尺度匹配；阈值 `0.78`，43 张非 M 素材最高误匹配 0.487。
7. 半透明 / 过曝菜单页：页签模板低于 `0.70` 时，比较 D–J 七个页签框的平均亮度，取明显更亮的激活页签；用右上角“返回”文字的亮度与边缘密度门控，避免战斗 HUD、地图与设置页误判。
8. 50 张源图全帧与顶部条带回归、7 条过曝页签合成条带全部通过；单帧平均约 36.2 ms，最大 74.4 ms。

完整阈值、模板裁剪框与回归数据见 [项目说明.md](项目说明.md)。

## 安全边界

- **只截屏**：仅读取屏幕顶部条带，不读取游戏内存、不注入进程、不修改游戏文件。
- **强杀限定**：强制结束前校验进程句柄与 token，只匹配 `EscapeFromTarkov.exe`，不会结束其他进程。
- **无作弊功能**：不提供透视、自瞄、物资提示、雷达或任何游戏内信息增强。
- **风险提示**：Alt+F4、自动按键与强制结束可能违反游戏服务条款或导致战局进度丢失；请在了解风险后自行决定是否使用。本项目与 BattlEye、Battlestate Games 无关联。

## 从源码构建

仓库包含界面源码、识别模块、构建脚本、21 张模板与三套主题图标。完整构建还需要：

- Windows 10 / 11 64 位
- Python 3.11 x64（`一键构建.bat` 默认使用 `tools\py311\python.exe`）
- `numpy`、`opencv-python-headless`
- 构建母版 `base\base_branded.exe`（V1.3.2.2 发布版骨架，59,672,615 字节，SHA256 `F6F733484E962B664FF147710B3EAF5C1816986A572AEDFE573AC66F4EE61FC8`；用途与注意事项见 `base\README.md`）
- 原始截图 `ui识别\`（因体积与隐私原因未随仓库分发，目录规范见 [ui识别/识别特征与识别画面.txt](ui识别/识别特征与识别画面.txt)）
- 测试图命名：`ui识别\` 下所有 `测试图*` 截图统一为 `{判定字母}{序号}_{得分}.png`，判定字母取当前检测器结果，序号按字母跨目录递增，得分保留 3 位小数；规则与维护方式见 [ui识别/测试图命名规则.txt](ui识别/测试图命名规则.txt)，本轮新旧对照见 `ui识别/测试图命名对照_20261028.csv`

准备好上述依赖后，双击 `一键构建.bat`，或按脚本顺序执行 16 步构建。使用系统 Python 时，把 BAT 中的 `tools\py311\python.exe` 替换为你的 `python.exe`。构建链包含 50 张源图识别回归、7 条过曝页签条带回归与撤离状态机测试，任一失败都会中止。

参考数据：用当前母版跑完整 16 步全部通过，产出 EXE `60,157,466` 字节（SHA256 `993372B8916867259A6E6FE0B90C244A5D64121D85B303C65CEEAC853FDD8ABC`）、ZIP `59,671,280` 字节（SHA256 `98D611E44B3D070E29E01433E6AE961E91EA06FAA344F1CDFD913876C206B885`）；50 张源图全帧与条带、7 条过曝条带与撤离状态机测试全部通过。

> 当前源码中的版本常量已同步为 `V1.4.1.0`，直接构建即得到与归档一致的正式版（从已裁剪母版构建时 PYZ 会追加约 484 KB 模块数据，体积略大于官方发布包，功能与识别结果相同）。

> 仓库不分发原始截图。`ui识别\画面识别 M 撤离结束\` 与 C 页 4 张新增地图截图都在本地保留原图；C 页模板直接取自 `识别特征3.png` ～ `识别特征6.png`，裁剪参数（`0,0,1920,240`）记录在 `scripts\build_ui_templates.py`。缺少任一目录时，第 5、6、8 步会直接报错而不是静默跳过。
